## 🎮 주요 조작법

| 동작 | 조작 방법 | 설명 |
| :--- | :--- | :--- |
| **위치 이동** | **캐릭터 좌클릭 드래그** | 화면 원하는 위치 어디로든 자유롭게 옮길 수 있습니다. |
| **타이머 토글** | **캐릭터 더블 클릭** | 타이머 시작(▶) 및 일시정지(⏸)가 바로 전환됩니다. |
| **시간 & 미니 버튼** | **캐릭터에 마우스 올리기 (Hover)** | 남은 시간, 상태(집중/휴식), 재생/스킵/리셋 버튼이 나타납니다. |
| **메뉴 열기** | **캐릭터 우클릭** | 멤버 변경, 타이머 스타일 변경, 다크/화이트 모드 토글, 상세 설정창, 종료 |

* **제나 (Zena)**: 시그니처 골드 옐로우 테마

## ⚡ 초경량 메모리 최적화 (26MB RAM)
* **스마트 해상도 디코딩**: 고해상도 원본 이미지를 위젯 규격에 맞게 480px로 최적 디코딩하여 텍스처 메모리를 80% 이상 절감했습니다.
* **비트맵 정적 캐싱**: 한 번 로드된 이미지를 재사용하여 반복 할당 누수를 차단했습니다.
* **Windows Working Set 자동 트리밍**: 유휴 상태의 페이징을 Windows 메모리 관리자에 즉시 반환하여 상시 **약 26MB**의 초경량 점유율을 유지합니다.

## 🖼️ 커스텀 캐릭터 사진 넣는 법
1. 캐릭터 우클릭 ➔ **[📂 캐릭터 이미지 폴더 열기...]** 클릭 (또는 `Images/` 폴더 진입)
2. 아래 파일명 규칙에 맞춰 투명 배경 PNG 사진을 덮어쓰기 하시면 즉시 적용됩니다:
   * 원이: `woni_focus.png` (집중) / `woni_break.png` (휴식)
   * 리브: `liv_focus.png` (집중) / `liv_break.png` (휴식)
   * 미나미: `minami_focus.png` (집중) / `minami_break.png` (휴식)
   * 메이: `may_focus.png` (집중) / `may_break.png` (휴식)
   * 제나: `zena_focus.png` (집중) / `zena_break.png` (휴식)

## 🎵 커스텀 멤버 음성 파일 넣는 법
1. 캐릭터 우클릭 ➔ **[🎵 멤버별 음성 폴더 열기...]** 클릭 (또는 `Sounds/` 폴더 진입)
2. 아래 파일명 규칙에 맞춰 오디오 파일(`.mp3` 또는 `.wav`)을 넣어주세요:
   * 원이: `woni_focus.mp3` / `woni_break.mp3`
   * 리브: `liv_focus.mp3` / `liv_break.mp3`
   * 미나미: `minami_focus.mp3` / `minami_break.mp3`
   * 메이: `may_focus.mp3` / `may_break.mp3`

## ⚙️ 상세 설정에서 조절 가능한 기능
* **🌐 언어 선택**: 한국어 (Korean) / English 즉시 전환
* **⏱️ 시간 맞춤 설정**: 집중 / 짧은 휴식 / 긴 휴식 시간 (슬라이더 및 키보드 직접 숫자 입력)
* **🎨 위젯 디자인 & 테마**: 간소화 / 표준 / 원형 링 스타일 선택 및 화이트 / 다크 테마
* **📐 크기 & 투명도**: 위젯 크기 (120px ~ 360px), 불투명도 (20% ~ 100%)
* **📌 부가 기능**: 항상 위에 표시(Topmost), 타이머 시간 상시 표시, 알림음 켜기/끄기
* **👀 실시간 미리보기 & 미저장 보호**: 설정창에서 슬라이더를 움직이면 즉시 바탕화면에 반영되며, 저장하지 않고 닫을 경우 확인 대화상자 표시
