# ✨ RESCENE 데스크톱 뽀모도로 마스코트 위젯 (RESCENE Pomodoro Pet)

윈도우 바탕화면에서 항상 맨 위에 띄워놓고 함께 집중하고 쉴 수 있는 **리센느(RESCENE) 데스크톱 뽀모도로 타이머 위젯**입니다!

---

## 🎮 주요 조작법

| 동작 | 조작 방법 | 설명 |
| :--- | :--- | :--- |
| **위치 이동** | **캐릭터 좌클릭 드래그** | 화면 원하는 위치 어디로든 자유롭게 옮길 수 있습니다. |
| **타이머 토글** | **캐릭터 더블 클릭** | 타이머 시작(▶) 및 일시정지(⏸)가 바로 전환됩니다. |
| **시간 & 미니 버튼** | **캐릭터에 마우스 올리기 (Hover)** | 남은 시간, 상태(집중/휴식), 재생/스킵/리셋 버튼이 나타납니다. |
| **메뉴 열기** | **캐릭터 우클릭** | 멤버 변경, 항상 위 On/Off, 설정창, 종료 등의 메뉴가 뜹니다. |

---

## 🌸 리센느 5인 멤버 지원
* **원이 (Woni)**: 시그니처 핑크 테마
* **리브 (Liv)**: 시그니처 라벤더 테마
* **미나미 (Minami)**: 시그니처 아쿠아 블루 테마
* **메이 (May)**: 시그니처 민트 테마
* **제나 (Zena)**: 시그니처 골드 옐로우 테마

> 캐릭터 우클릭 ➔ **[👤 리센느 멤버 선택]** 또는 **[⚙ 상세 설정]**에서 언제든 멤버를 바꿀 수 있습니다.

---

## 🖼️ 내가 가진 실제 리센느 캐릭터/누끼 사진 넣는 법

프로그램에 기본적으로 예쁜 10장의 고화질 더미 투명 이미지가 생성되어 작동 중입니다.  
실제 리센느 멤버 사진(배경이 투명한 PNG)으로 교체하고 싶으시다면:

1. 캐릭터 우클릭 ➔ **[📂 캐릭터 이미지 폴더 열기...]** 클릭 (또는 프로젝트 내 `Images/` 폴더 진입)
2. 아래 파일명 규칙에 맞춰 원하는 사진을 덮어쓰기(바꿔치기) 하시면 됩니다:
   * 원이: `woni_focus.png` (집중) / `woni_break.png` (휴식)
   * 리브: `liv_focus.png` (집중) / `liv_break.png` (휴식)
   * 미나미: `minami_focus.png` (집중) / `minami_break.png` (휴식)
   * 메이: `may_focus.png` (집중) / `may_break.png` (휴식)
   * 제나: `zena_focus.png` (집중) / `zena_break.png` (휴식)

## 🎵 멤버별 음성 파일 넣는 법

집중 시작할 때, 휴식 시작할 때 각 멤버의 실제 목소리가 나오도록 음성 파일을 넣을 수 있습니다!

1. 캐릭터 우클릭 ➔ **[🎵 멤버별 음성 폴더 열기...]** 클릭 (또는 프로젝트 내 `Sounds/` 폴더)
2. 아래 파일명 규칙에 맞춰 음성 파일(`.mp3` 또는 `.wav`)을 넣어주세요:
   * **원이 (woni):** `woni_focus.mp3` (집중 시작) / `woni_break.mp3` (휴식 시작)
   * **리브 (liv):** `liv_focus.mp3` (집중 시작) / `liv_break.mp3` (휴식 시작)
   * **미나미 (minami):** `minami_focus.mp3` (집중 시작) / `minami_break.mp3` (휴식 시작)
   * **메이 (may):** `may_focus.mp3` (집중 시작) / `may_break.mp3` (휴식 시작)
   * **제나 (zena):** `zena_focus.mp3` (집중 시작) / `zena_break.mp3` (휴식 시작)
3. 파일이 아직 없는 경우에는 부드러운 기본 알림음이 재생되므로 안심하셔도 됩니다!

## ⚙️ 상세 설정에서 조절 가능한 기능
* **🌐 언어 선택 (한국어 / English 다국어 완벽 지원)**
* **⌨️ 집중 시간 / 짧은 휴식 / 긴 휴식 시간 (슬라이더 및 키보드 직접 숫자 입력)**

* **위젯 불투명도 조절 (20% ~ 100%)**

* **타이머 시간 항상 보기 On/Off** (끄면 마우스 올릴 때만 시간 표시)
* **단계 전환 시 효과음 및 멤버 목소리 알림 On/Off**
